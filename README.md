# Eliton Penke — Portfólio

Portfólio pessoal de Eliton Penke, desenvolvido para apresentar projetos, especialidades e formas de contato.

🌐 **Acesse:** [elitonassessoria.com](https://elitonassessoria.com)

## Recursos

- Layout responsivo
- Idiomas português e inglês
- Alternância entre tema claro e escuro
- Formulário de contato integrado ao Gmail
- Seções de apresentação, especialidades e projetos

## Tecnologias

HTML, CSS e JavaScript.

## Publicação

O deploy é automatizado pelo GitHub Actions: a cada merge na `main`, o site é publicado na hospedagem HostGator via cPanel, usando secrets do GitHub. As atualizações ficam disponíveis em poucos segundos.
